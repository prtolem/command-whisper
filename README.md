# Command Whisper

Лёгкая нативная macOS-утилита для голосового ввода.

- Зажмите **правый Command** на 0,22 секунды и говорите.
- Живой эквалайзер в нижней панели реагирует на громкость голоса.
- Отпустите клавишу — текст распознается и очищается.
- Текст всегда сохраняется в буфер обмена, а при наличии активного поля ещё и вставляется в него.
- Обычные сочетания с правым Command не запускают диктовку.
- Распознавание идёт локально через системный Speech framework, если русский пакет установлен; иначе автоматически используется сетевое распознавание Apple.
- Приложение не содержит Electron, Python-сервера или отдельной Whisper-модели.

## Установка

Скачайте DMG из [последнего GitHub Release](https://github.com/prtolem/command-whisper/releases/latest) и дважды нажмите **Install Command Whisper.command**. Установщик положит приложение в `~/Applications`, проверит подпись и запустит его. При первом запуске появится мастер разрешений для микрофона, распознавания речи, мониторинга ввода и универсального доступа. После выдачи разрешений перезапуск не нужен.

Можно и просто перетащить **Command Whisper** в **Applications**. Поскольку приложение пока не нотарифицировано платным Apple Developer ID, macOS может потребовать подтвердить запуск в **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.

Для локальной установки из исходников:

```sh
./scripts/install-local.sh
```

Если macOS сообщает, что локальное распознавание недоступно, включите Диктовку и русский язык в **Системные настройки → Клавиатура → Диктовка**.

## Обновления

В приложение встроен Sparkle 2.10.0. Оно проверяет подписанный Ed25519-ключом `appcast.xml` из последнего GitHub Release раз в шесть часов и может установить новую версию автоматически. Исходники публичны, а готовые DMG, ZIP и appcast распространяются только через GitHub Releases.

## Сборка

```sh
./scripts/build-app.sh
```

Для тестов очистки текста:

```sh
./scripts/test.sh
```

Полная проверка app-бандла, подписи, фреймворка обновлений и диагностического режима:

```sh
./scripts/smoke-test.sh
```
