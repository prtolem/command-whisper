# Command Whisper

Лёгкая нативная macOS-утилита для голосового ввода.

- Зажмите **правый Command** на 0,22 секунды и говорите.
- Живой эквалайзер в нижней панели реагирует на громкость голоса.
- Отпустите клавишу — текст распознается и очищается.
- Текст всегда сохраняется в буфер обмена, а при наличии активного поля ещё и вставляется в него.
- Обычные сочетания с правым Command не запускают диктовку.
- Распознавание идёт локально через системный Speech framework, если русский пакет установлен; иначе автоматически используется сетевое распознавание Apple.
- Приложение не содержит Electron, Python-сервера или отдельной Whisper-модели.

## Установка

Откройте DMG, перетащите **Command Whisper** в **Applications** и запустите приложение. При первом запуске появится мастер разрешений для микрофона, распознавания речи, мониторинга ввода и универсального доступа. После выдачи разрешений перезапустите приложение.

Для локальной установки из исходников:

```sh
./scripts/install-local.sh
```

Если macOS сообщает, что локальное распознавание недоступно, включите Диктовку и русский язык в **Системные настройки → Клавиатура → Диктовка**.

## Обновления

В приложение встроен Sparkle 2.10.0. Оно проверяет подписанный Ed25519-ключом канал обновлений раз в шесть часов и может установить новую версию автоматически. Исходный репозиторий приватный; GitHub Pages публикует только подписанный appcast и готовый ZIP приложения.

## Сборка

```sh
./scripts/build-app.sh
```

Для тестов очистки текста:

```sh
./scripts/test.sh
```

Полная проверка app-бандла, подписи, фреймворка обновлений и диагностического режима:

```sh
./scripts/smoke-test.sh
```
